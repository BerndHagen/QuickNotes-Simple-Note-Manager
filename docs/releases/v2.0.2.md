QuickNotes `2.0.2` is a visual-system and interface-consistency release. It replaces one-off component styling with shared product primitives, restores a clear light workspace, and gives the authentication screen, navigation rail, dialogs, note cards, and editor a coherent edge-to-edge design.

### Unified Design System

- **One control language**: primary actions, secondary actions, icon toggles, focus rings, disabled states, and active states now come from shared button and control definitions instead of dozens of hand-built variants.
- **Consistent dialogs and panels**: dialog headers use the same restrained banner material as the editor, while content panels, wells, borders, and text use common design tokens in light and dark themes.
- **One tag component everywhere**: the rail, note cards, and editor banner now share the same tag shape, tint, border, and readable text treatment without redundant color dots or removable-pill variants.
- **Semantic color stays meaningful**: application structure uses the QuickNotes green system, while priorities, moods, kanban columns, energy levels, and other status information retain purpose-specific colors.

### Workspace and Editor Layout

- **The editor fills its pane again**: a temporary width cap that pushed text into a narrow centered column on ultrawide displays was removed. Banner texture is bounded independently so content can use the available workspace.
- **Complete note-card borders**: resting cards have a visible border on all four sides, and the hover accent uses an inset treatment instead of replacing the left edge.
- **Pin and favorite no longer overlap**: both indicators share a reserved action cluster, keeping long titles readable and every state independently visible.
- **Quick Note matches other primary actions**: the navigation action uses the shared accent button instead of disappearing into the dark rail or introducing another color recipe.

### Authentication Canvas and Brand Presentation

- **Real contour-wave artwork**: the outer canvas uses responsive SVG geometry with broad layered bands rather than stacked gradients that could not reproduce the intended crossing curves.
- **Correct light and dark canvases**: the light workspace remains a light professional surface, while dark mode uses a deep neutral treatment. The rail and banner retain the saturated brand green without merging into the background.
- **No clipped onboarding content**: the hero, preview, and supporting feature content step down gracefully on laptop-height displays instead of overflowing the authentication frame.
- **Crisp, correctly scaled branding**: the square logo, authentication preview, and startup screenshot use current artwork without rasterizing perspective transforms or stretched proportions.

### Content and Repository Presentation

- **A useful starter note**: the welcome content now explains the three-pane layout, folders versus tags, structured workspaces, shortcuts, Trash retention, version history, archive, note links, and export formats.
- **Current product screenshots**: the repository images show populated, current workflows and follow the same naming convention as the related application repositories.
- **Reliable token behavior**: unsupported opacity combinations around variable-backed colors were removed so panels and controls no longer depend on accidental page backgrounds.
