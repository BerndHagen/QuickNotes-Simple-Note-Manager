QuickNotes `1.1.2` expands editor precision and account control. It introduces a true two-axis ruler, makes editor preferences affect the document itself, adds permanent account deletion and an About section, and broadens import, sorting, Trash, localization, and folder customization options.

### Editor Precision and Preferences

- **Horizontal and vertical rulers**: the editor can display centimeter and millimeter markings on both axes, including responsive width measurement and a joined corner reference.
- **Editor settings now affect the document**: font family, font size, line height, word wrapping, tab size, spellcheck, autocorrect, and current-line highlighting are applied directly to the editor surface.
- **Visible document structure**: spaces and paragraph boundaries can be shown in light and dark themes without becoming part of the note content.
- **Readable ruler geometry**: centimeter numbers, major marks, half-centimeter marks, and millimeter ticks remain distinct instead of overlapping.

### Account and Data Controls

- **Permanent account deletion with deliberate confirmation**: cloud users must type `DELETE` before QuickNotes removes the account and associated data.
- **A complete About section**: Settings now includes version information, repository access, Privacy and Terms links, and open-source information.
- **Import from Settings**: the existing import workflow is reachable directly from the Data section.
- **Configurable Trash retention**: automatic cleanup can be set to 7, 14, 30, 60, or 90 days instead of a fixed period.
- **Default sorting preference**: users can choose among nine default note-ordering modes.

### Navigation, Customization, and Language

- **A visible active Settings section**: the selected section receives a clear navigation accent rather than relying on subtle background variation.
- **A larger folder catalogue**: 53 additional folder icons and consistent create/edit grids make visual organization easier to scan.
- **Nine-language coverage**: the new account, data, editor, sort, retention, About, and import controls are translated across every supported interface language.
- **Reliable portaled folder menus**: folder context menus render above surrounding content instead of being clipped by their parent layout.
