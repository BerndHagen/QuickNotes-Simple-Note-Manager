QuickNotes `2.3.0` turns the application into a substantially stronger daily workspace: it adds cross-note planning and reusable organization, rebuilds the document editor around dependable pages and professional controls, hardens mobile and cloud behavior, and gives light and dark themes a coherent production visual system.

### Daily Planning and Organization

- **One dependable Today entry point**: Today creates or reopens exactly one local-date journal, so a daily note is never duplicated or silently filed inside the folder a user happened to be browsing.
- **Tasks from every workspace in one place**: My Tasks combines document checklists, task-list items and subtasks, project work and milestones, meeting actions, journal goals, and weekly-plan tasks with source navigation, search, useful status filters, priorities, due-state context, and direct completion.
- **Recurring work preserves history**: daily, weekday, weekly, monthly, and yearly recurrence can use a custom interval; completing an occurrence retains it and creates the next due item instead of moving the same task forward.
- **Smart Views make large collections manageable**: reusable all/any rules cover text, title, tags, folders, note types, favorites, pins, task and reminder state, and created or updated dates, with scope, sorting, live counts, editing, safe deletion, offline persistence, cloud sync, and backup support.
- **User templates preserve real workflows**: documents and every structured workspace can be saved as reusable templates with inherited tags, favorites, and `{{title}}`, `{{date}}`, and `{{time}}` variables.
- **Search understands structured notes**: global search now indexes structured workspace content and offers focused type filters instead of limiting retrieval to ordinary rich-text notes.

### Document Editing and Export

- **Stable paginated documents**: standard notes flow across visible A4 sheets without allowing checklists or other content to stretch one page forever; durable manual page breaks and page geometry are preserved during editing and PDF export.
- **Professional paragraph layout**: horizontal and vertical rulers expose margin regions, first-line and left/right indents, paragraph spacing, and left, center, right, or decimal tab stops that the Tab key follows.
- **Customizable checklists**: each checkbox can use its own shape, checked colour, size, and completion treatment, while persistent defaults make repeated list creation predictable.
- **Editable document objects**: a categorized gallery provides 46 SVG shapes with direct movement, eight-handle sizing, rotation, flips, wrapping, exact geometry, fill, and border controls; text boxes share the same dependable object model.
- **Useful review and view commands**: slash insertion, semantic callouts, document outline, formatting marks, statistics, accessibility issue navigation, translation, dictation, focus mode, and HTML source editing are organized around user intent across Home, Insert, Layout, Review, and View.
- **Faithful PDF output**: self-contained A4 PDF export retains rich formatting, paper styles, document geometry, manual page boundaries, and avoids unintended blank pages.

### Mobile, Visual Design, and Accessibility

- **Mobile editing opens directly and predictably**: tapping a note opens the editor without a hover-preview card, the header has one back control and an editable centered title, and tabs and note actions remain reachable on compact screens.
- **One professional application hierarchy**: the former double-green editor border is replaced by one clear title bar and a neutral command surface, with centered note identity and consistently aligned actions.
- **Dark mode uses deliberate charcoal surfaces**: navigation, editor chrome, Settings, and shared windows no longer mix broad green panels into a gray workspace; green is reserved for selection, focus, toggles, and interaction feedback.
- **Light mode keeps a restrained brand anchor**: branded navigation remains recognizable while document, list, and dialog surfaces use quieter neutrals and readable contrast.
- **Icons are consistent across platforms**: favorites use the same gold Lucide star in list, grid, editor, and task views, avoiding emoji substitution on iOS; window icons and headers now share the same alignment system.
- **Critical contrast and responsive behavior are covered**: low-contrast navigation, the New Note button, authentication visuals, dialogs, safe areas, short viewports, and WCAG A/AA regressions have dedicated browser checks.

### Sync, Recovery, and Cloud Data

- **Background sync stays quiet and single-flight**: overlapping sync requests share one in-progress operation, background success is silent, and a manual Sync Now action produces one result instead of repeated success notifications.
- **Version history stores recovery points, not duplicate notes**: document and structured changes create typed checkpoints, adjacent identical cloud snapshots are suppressed during retries, and local and remote history retain only the newest 30 states per note.
- **Cloud organization is tenant-isolated**: Smart Views and templates have owner-scoped Supabase tables, row-level security, constraints, indexes, sync handling, and backup/restore coverage.
- **Trash cleanup remains recoverable and scoped**: active-note indexes improve common queries, while expired Trash purging can only remove the signed-in user’s eligible rows.
- **Deployment checks protect real workflows**: release builds pass lint, unit and browser suites, mobile WebKit coverage, accessibility scans, PWA/deep-link/offline validation, and deployed critical-path verification before publication.
