QuickNotes `1.1.1` is a workflow and visual-consistency update. It makes several Settings options effective in the editor, fixes context and folder menus rendered through portals, and gives controls, cards, badges, and dialogs clearer boundaries and interaction feedback.

### Settings That Affect the Workspace

- **Live spellcheck control**: the Settings preference updates the rich-text editor immediately instead of existing as a disconnected toggle.
- **Optional deletion confirmation**: note deletion asks for confirmation only when the preference is enabled, across editor, list, and grid workflows.
- **Optional note statistics**: the word, character, and reading statistics area follows its visibility setting.
- **Complete localization**: the new editor preferences and confirmation message are available across all nine supported languages.

### Menus and Navigation

- **Context-menu actions fire reliably**: portaled menus are excluded from premature outside-click dismissal, so the selected action executes before the menu closes.
- **Move to Folder stays in view**: the destination popover uses a portal and no longer clips against the note list or editor shell.
- **No width jump in the note list**: the desktop list retains its width while the mobile view state changes.
- **No collapsed-sidebar overlap**: the sidebar toggle no longer covers the All Notes heading.

### Visual Consistency

- **Clear control boundaries**: light-mode inputs, cards, dialogs, action buttons, stat boxes, and editor settings use a consistent visible border system.
- **Stronger menu feedback**: context-menu rows have clearer light and dark hover states, rounded geometry, and spacing.
- **Consistent navigation counts**: All Notes, Favorites, Shared, Archive, Trash, and folder badges share the same shape and border treatment.
- **A broader folder palette**: 54 organized colors and a corrected icon/color grid make folder creation easier to scan.

### Focus and Voice Reliability

- **Ambient sounds start from the user gesture**: Focus Mode audio is played directly from the click action so browser autoplay rules do not block it unexpectedly.
- **Voice errors stop cleanly**: recognition failures no longer restart an error loop.
- **No duplicate sync notification**: reload synchronization uses one active guard and produces one status result.
