QuickNotes `2.2.0` is a broad usability and reliability release. It makes linked-note navigation exact, establishes one clear username identity, strengthens shared-note organization and privacy, and brings the mobile, editor, settings, and dialog experiences into one consistent product system.

### Linked Notes and Navigation

- **Open the note you selected**: clicking an inserted note badge now selects that exact destination in the current workspace. Links no longer open an empty browser fragment or leave another note, such as the source note, selected.
- **Safer link choices**: the current note and notes in Trash are excluded from Insert Note Link. Stable note IDs preserve links and backlinks when a destination moves between folders.
- **Production regression coverage**: the deployed GitHub Pages build is now tested for exact linked-note selection after every release deployment.

### Identity and Shared Notes

- **One username everywhere**: registration, account settings, the sidebar, avatars, invitations, and ownership labels now use one case-preserving username. A chosen name such as `VampyrusNoctis` is no longer replaced by a generated lowercase or suffixed variant.
- **Case-insensitive uniqueness without silent renaming**: usernames retain their chosen casing while collisions are checked case-insensitively. If a name is already in use, QuickNotes reports that directly instead of mutating it.
- **Useful ownership information**: Shared with me shows the real privacy-safe owner username and permission level rather than a generic owner label or an internal-looking generated identifier.
- **Better shared-note organization**: shared collections can be searched by note or owner, filtered by permission, ordered by recent activity, and acted on with clearer open and leave controls.
- **Trash-aware collaboration**: trashed notes disappear from invitations and collaborator access, while restoring a note restores its prior collaboration relationship.

### Mobile and Editor Experience

- **A real mobile grid**: Grid view uses two columns on phones, while List view remains a compact single column. The two modes now provide meaningfully different layouts.
- **Stronger phone and tablet behavior**: touch targets, editor toolbars, dialogs, safe areas, orientation changes, short viewports, and Mobile Safari history and draft handling were hardened across the application.
- **Consistent QuickNotes context menus**: right-clicking in the editor canvas or elsewhere in the application opens the appropriate QuickNotes menu instead of mixing it with the browser or operating-system menu.
- **A complete cross-platform font catalogue**: the editor now includes 39 bundled families grouped as System, Sans Serif, Serif, and Monospace. Every option names one font and renders consistently across supported operating systems.
- **Flags that render everywhere**: code-native language flags replace platform-dependent emoji, so the same visual appears on desktop and mobile.
- **Accurate invisible characters**: spaces, tabs, hard breaks, and paragraph boundaries are rendered as editor decorations without changing saved HTML or copied text.
- **A composed document workbench**: the editor is now a centered, elevated note surface instead of one unstructured white area. Focused, standard, wide, and full-width modes are persistent preferences.
- **Customization that affects real work**: one visible editor-customization entry point controls ribbon spacing, group labels, the initial tab, note width, ruler visibility, typography, tab size, browser auto-correction, and defaults for new checklists.
- **Checklists are editable objects**: each item can independently use a square, rounded, or circular box; six checked colours; three sizes; and strike, fade, or unchanged completion text. Current-item actions toggle completion, add above/below, or remove only that checkbox.
- **Structural writing without toolbar overload**: typing `/` on an empty line opens a searchable keyboard menu for headings, lists, checklists, callouts, quotes, code, dividers, tables, and dates. Insert also exposes editable semantic callouts and local date/time commands.
- **Professional paragraph control**: Layout now stores exact spacing before and after paragraphs. The ruler remains an explicit on/off preference and no longer appears merely because the Layout tab was opened.

### Visual Consistency and Feedback

- **One dialog language**: shared notes and remaining legacy windows use the common modal structure, banner treatment, controls, focus behavior, and responsive scrolling.
- **Texture stays on banners**: primary actions such as Export Note use the standard solid button treatment instead of inheriting decorative banner texture.
- **Clearer settings state**: grouped controls use a consistent hierarchy and the selected Settings section has visibly stronger feedback.
- **Honest save and sync status**: QuickNotes distinguishes saved locally, waiting to sync, syncing, offline, failed, and fully synchronized states instead of showing an endless or misleading Saving indicator.
- **More readable interaction states**: tooltip contrast, dropdown focus, selection tint, hover feedback, pin and favorite state, and note-card action alignment were corrected in light and dark themes.

### Data Integrity and Verification

- **Reliable delete and restore behavior**: soft deletion is idempotent, uses one tombstone timestamp, and coalesces offline queue operations so repeated actions and insert-to-delete races converge safely.
- **Hardened Supabase boundaries**: migrations add privacy-safe usernames, shared-note provenance, case-insensitive username availability, and active-note checks without exposing email addresses.
- **A deployment gate for critical workflows**: the production suite verifies username uniqueness, note-link navigation, mobile grid/list geometry, custom context menus, the font catalogue, and export styling against the live site.
