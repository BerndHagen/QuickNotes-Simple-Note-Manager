QuickNotes `3.0.1` is a compatibility and interface-quality update that makes daily editing more reliable across desktop and mobile while preserving the local-first 3.0 workspace model.

### Document and Paper editing

- **Clear multi-page document boundaries**: Each visual page now paints its own complete shadow and focus edge, with a clean gutter that no longer makes adjacent sheets look connected.
- **Reliable live document statistics**: The footer and inspector now share one rendered-text calculation, retain boundaries between headings, paragraphs, and list items, and report the same word and character totals.
- **More usable Paper workspaces**: Page thumbnails show real page content, delete controls remain fully reachable, colour controls no longer clip, and active ink remains visible throughout rapid mouse and touch drawing.

### Navigation and responsive work

- **Consistent workspace pane controls**: Navigation, note-list, and inspector toggles now form one predictable control group with matching selected, hover, focus, and accessible pressed states.
- **Professional compact title treatment**: Document actions keep a deliberate gap from the title, while pin and favourite status align independently in note rows instead of attaching to short title text.
- **Full mobile editing parity**: Phone users can draw, select, move, resize, reorder, duplicate, delete, record, annotate, and use contextual editor actions through touch-first controls without desktop-only interaction requirements.

### Interface consistency

- **Unified application styling**: Authentication, dialogs, Focus Mode, native lists, empty states, sticky notes, colour pickers, and editor controls use the same restrained surfaces, readable colour pairs, and inset focus treatment.
- **Restored project presentation**: The repository README again follows the established QuickNotes structure, table of contents, and even screenshot layout while retaining current 3.0 product information.
