QuickNotes `1.1.0` establishes the first permanent versioned-release line and expands the product beyond standard rich-text notes. Structured workspaces can be exported, core dialogs and editor surfaces receive broader localization, and navigation, selection, synchronization, and context-menu feedback are strengthened throughout the application.

### Structured Note Export

- **Export every specialized note type**: task lists, shopping lists, meetings, journals, brainstorms, projects, and weekly plans can be transferred instead of limiting export to standard notes.
- **Structured fields remain meaningful**: export covers the dedicated fields used by each workspace rather than flattening the experience into an incomplete generic note.

### Localization and Editor Presentation

- **Broader German coverage**: Settings, Export, Import, Note Types, and Quick Note workflows no longer fall back to hardcoded English strings.
- **Localized dates**: date presentation follows the selected interface language.
- **A recognizable editor banner**: the note title area adopts the QuickNotes green identity with readable text and controls.
- **A clearly selected note**: the active list or grid card receives a stronger surface and shadow instead of blending into surrounding notes.

### Navigation and Interaction Feedback

- **More visible menus and controls**: context menus, search, cancel actions, sidebar badges, folder/tag controls, and modal boundaries have stronger light-theme hover and border states.
- **Context menus stay inside the usable window**: editor overflow no longer clips the menu when it opens near an edge.
- **One synchronization result**: an active sync guard prevents duplicate completion messages.
- **Consistent structured-editor inputs**: meeting, task, weekly, journal, brainstorm, and shopping fields share clearer interactive boundaries.

### Release Delivery

- **Permanent semantic releases**: version tags create fixed downloadable archives, while the `latest` prerelease tracks the current `main` build separately.
- **Predictable version ownership**: release numbers are chosen deliberately instead of being auto-incremented on every build.
- **A dedicated rolling preview**: users can try the newest build without replacing or rewriting a stable versioned milestone.
