QuickNotes 3.0 is a local-first workspace release centered on durable daily use: Documents, Paper, Canvas, structured planning, knowledge retrieval, capture, and recovery now share one tested data and interaction model.

### Documents, Paper, and Canvas

- **Three purpose-built surfaces**: Paginated rich-text Documents, page-oriented Paper, and an infinite Canvas now live in the same professional shell while retaining editor-specific commands, history, and rendering.
- **Canonical spatial work**: Pressure-aware ink, highlighter, erasing, selection, shapes, text-like objects, images, note links, z-order, undo/redo, replay, and export persist as bounded vector/source records rather than flattened pixels.
- **Daily-work workspaces**: Task, project, meeting, journal, brainstorm, shopping, and weekly-plan editors connect to folders, tags, favorites, pins, templates, Smart Views, Trash, and Task Center.

### Knowledge, capture, and meetings

- **Independent lexical retrieval**: Fast local search covers documents, structured notes, supported spatial content, tags, and reviewed recognition, with stable note links, anchors, backlinks, filters, and source return.
- **Non-destructive capture**: Local image OCR, local PDF text extraction and scanned-page OCR, PDF/image annotation, canonical audio recording, and supported browser handwriting or speech recognition retain the original source and recognition provenance.
- **Meeting follow-through**: Agenda, notes, recordings, transcript segments, decisions, actions, reminders, and source navigation form one reviewable workflow without silently generating or mutating tasks.

### Sync, backup, and recovery

- **Conflict-aware optional cloud sync**: Owner-scoped catalog, spatial, capture, and annotation outboxes use immutable operations, atomic acknowledgement, reference-aware resources, explicit conflict decisions, and immediate authorization revocation through Supabase policies.
- **Complete portable archives**: Versioned `.qnotes` backup includes canonical binary resources, spatial and annotation graphs, recognition corrections, reminder/source identities, recording recovery state, and retained versions with bounded validation, checksum verification, ID remapping, and atomic import.
- **Failure-visible local-first behavior**: Save, quota, network, authentication, migration, missing-resource, and corrupt-index failures remain visible and recoverable; derived indexes can be rebuilt without rewriting canonical content.

### Security, privacy, and compatibility

- **Private processing by default**: Local-only recognition never falls back to browser-managed or external processing, and external work requires capability checks plus fresh operation consent.
- **Hardened trust boundaries**: Sanitized rendering, bounded imports and payloads, account-scoped local stores, RLS, Storage policies, validation triggers, authenticated functions, multi-tab coordination, and deletion tombstones protect canonical data and tenant isolation.
- **Additive upgrade path**: Existing IndexedDB and Supabase migrations remain ordered and compatibility-preserving; users should create a current backup before upgrading any important workspace.

Paid provider-backed AI actions, embeddings, semantic search, grounded Q&A, and imported-audio provider transcription are intentionally deferred and are not available in the hosted 3.0 release. Browser speech/handwriting depends on platform support. Shared Paper, Canvas, and annotations are read-only for collaborators rather than same-object realtime co-editing. The connected Supabase Free project does not use leaked-password screening; deployments requiring that protection should enable the applicable Auth plan/setting.
