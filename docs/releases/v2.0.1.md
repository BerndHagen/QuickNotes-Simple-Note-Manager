QuickNotes `2.0.1` is a focused local-workspace recovery release. It restores dependable account-free use on cloud-capable builds, clarifies local save state, and aligns the navigation rail and brand presentation with the authentication experience.

### Local Workspace Reliability

- **Private local workspaces stay open**: choosing the account-free workspace no longer returns to the sign-in screen when no cloud session exists. Local mode is treated as a valid session rather than an expired cloud login.
- **Reload without losing the workspace**: a local workspace survives page refreshes on builds that also support Supabase accounts.
- **Clean local startup and shutdown**: entering local mode no longer triggers a shared-note loading error, and leaving it ends the session while preserving notes on the device.
- **Truthful save status**: local workspaces show `Saved locally` instead of counting changes that are intentionally never uploaded.

### Navigation and Brand Consistency

- **One visual material from sign-in to workspace**: the navigation rail and authentication hero share the same product surface so the transition into QuickNotes feels continuous.
- **A consistent application mark**: the rail, authentication header, workspace preview, favicon, and installable-app icons use the current logo artwork.
- **Full-width authentication layout**: ultrawide displays no longer show unintended white margins around a capped sign-in composition.

### Keyboard Access

- **Reachable editor statistics**: the word and character status track can be scrolled with the keyboard when its content exceeds the available width.
