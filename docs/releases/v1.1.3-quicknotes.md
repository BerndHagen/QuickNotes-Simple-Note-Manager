QuickNotes `1.1.3` expands the structured-note workflow and makes tags, folder customization, version history, and editor actions more consistent. The release also places firm limits on retained history so long-running workspaces remain manageable.

### Structured Note Workflows

- **Shared actions across specialized editors**: task, project, meeting, journal, brainstorm, shopping, and weekly notes expose the actions that work for their data model, including voice input, version history, duplicate, export, and reminders.
- **Version history for every note type**: structured `noteData` is saved and restored alongside ordinary rich-text content.
- **Voice input follows focus**: dictated text is inserted into the active field or text area in specialized editors.
- **Note-type conversion**: existing notes can be converted from their context menu when moving a workflow into a different structured format.

### Tags and Folder Customization

- **A full tag color palette**: tags use the same broad, hue-organized palette available to folders.
- **Clear multi-tag selection**: the picker stays open, shows every tag with a checkmark, and communicates `No tags`, `1 Tag`, or the current count without removable pills competing with the menu.
- **Consistent tag appearance**: tags use readable tinted surfaces, matching borders, and stable spacing in cards and editor metadata.
- **More folder identities**: 40 additional icons broaden the folder catalogue without changing existing selections.

### Version-History Governance

- **A firm 30-version limit**: excess local and merged history entries are cleaned during read and save operations so older workspaces cannot grow without bound.
- **Existing oversized histories recover automatically**: notes already above the limit are normalized the next time their history is loaded or saved.

### Interface Polish

- **Aligned create and edit dialogs**: folder dialogs share sizing and grid behavior, while Quick Note presentation is aligned in the note-type chooser.
- **Cleaner editor metadata**: time, folder, tag controls, counts, chevrons, and popovers use consistent spacing and placement.
- **Better preference coverage**: preview lines, date format, compact mode, and autosave delay received the translation keys needed for localized settings.
